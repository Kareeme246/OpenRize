# Security Policy

## Reporting a vulnerability

Please report security issues privately to **support@offlinestudios.net** rather than opening a
public GitHub issue. Include as much detail as you can (steps to reproduce, affected version,
platform) so the report can be triaged quickly.

## Privacy-sensitive surface

OpenRize reads the titles of the windows you have open, using the macOS Accessibility permission,
to categorize your activity. This happens entirely on-device - window titles never leave your
Mac. If you find a way for that data (or any other local data OpenRize stores) to be read,
exfiltrated, or exposed without the user's action, please report it privately as above rather than
filing a public issue.
